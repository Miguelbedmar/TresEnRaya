# TresEnRaya

# Objetivo
El objetivo de este proyecto es recordar y repasar lo aprendido durante 
el primer año del grado superior de desarrollo de aplicaciones multiplataformas
 # Descripcion
 Se  ha realizado un tres en raya en java en donde te pedira las posiciones primero la fila y luego la columna , el tablero se dibuja entre los toStrings de la clase tablero y de partida 
 EL sistema es capaz de detectar un ganador ya sea en horizontal ,vertical , diagonal ,diagonal inversa  o empate
